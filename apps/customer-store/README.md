# Customer Store App

Base frontend para clientes de Patio Sarduy.

## Incluye
- React + TypeScript + Vite
- Tailwind CSS v4 + shadcn
- Redux Toolkit para estado global
- TanStack Query para cache de servidor
- React Router para navegacion
- Axios para cliente HTTP

## Scripts
- `pnpm --filter customer-store dev`
- `pnpm --filter customer-store build`
- `pnpm --filter customer-store lint`
